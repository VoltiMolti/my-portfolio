About the Project

  • Custom Discord bot built with Python and discord.py
  • Full moderation toolkit with permission checks
  • Interactive ticket system using buttons and forms
  • Every command available as both classic and slash command

Bot Features

  • Moderation commands: kick, ban, unban, warn, mute, unmute, clear
  • Persistent warning system stored per member
  • Reaction roles — members get a role automatically by reacting to a message
  • Ticket system with a button, a pop-up form and a dedicated ticket category
  • One-click ticket closing
  • Automatic logging channel for every moderation action
  • Welcome embed with the new member's profile picture

Technical Details

  • Hybrid commands (discord.py) for combined "!" and "/" usage
  • Role- and permission-based access control per command
  • Token stored securely using environment variables
  • JSON-based persistent storage for warnings
